# un document légal cliqué doit s'OUVRIR, pas se télécharger

Depuis le site comme depuis l'app, cliquer un document déclenche un téléchargement au lieu de
l'afficher. Ce sont des fichiers HTML : on doit pouvoir les lire dans l'onglet.

**Cause identifiée** : `deva/pulumi/modules/puassets/sync.py` téléverse tout en
`application/octet-stream` — en dur ligne 569 pour `_upload_file`, et par défaut dans
`_upload_bytes`. GCS ressert ce type tel quel, et le navigateur télécharge au lieu de rendre.
Il faut déduire le type du suffixe (`.html` → `text/html; charset=utf-8`, `.pdf` →
`application/pdf`) au moins pour le chemin `sync_documents`.

⚠ Corriger l'upload ne suffit pas pour les fichiers **déjà en place** : le type est figé à
l'objet. Il faudra soit re-téléverser, soit patcher les métadonnées des objets existants.
