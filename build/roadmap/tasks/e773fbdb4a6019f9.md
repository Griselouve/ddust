# Finaliser la validation des développeurs Android (clone .dev et nouvelle entrée d'app)

## Contexte

Google exige que toute app installable sur un Android certifié soit rattachée à un
développeur vérifié, avec son nom de package et ses clés de signature enregistrés.
Play Console → Validation des développeurs Android.

- `com.grisloup.ddust_client` : **Enregistrée** depuis le 2026-08-21, 4 clés.
- `com.grisloup.ddust_client.dev` (clone APK distribué hors Play) : preuve de
  propriété déposée le 2026-10-03, **En cours d'examen**.

Pour une app hors Play, l'enregistrement conditionne l'installation dans certains
pays d'abord, puis dans le monde entier à partir de 2027.

## Ce qu'il faut faire

1. Vérifier que `com.grisloup.ddust_client.dev` passe à **Enregistrée**.
   Puis supprimer `E:\Deva\tmp\adi-registration-ddust_client_dev.apk`.
2. Si le reboot du package est confirmé : enregistrer la nouvelle entrée d'app
   (et son clone `.dev`) sur la même page, avec la même procédure.

## Procédure de preuve (pour un package hors Play)

- Clé : keystore `dvddust__android_keystore_client` (Secret Manager, projet
  `dvddust`), alias `ddust`. SHA-256 :
  `59:45:53:25:6A:50:46:19:66:3C:3D:F0:AF:EC:59:EF:62:06:3B:AF:8D:78:C5:11:0A:6D:18:0C:8E:C6:2F:FB`
- Google fournit un extrait à placer dans `assets/adi-registration.properties`.
- APK de preuve fabriqué SANS le builder ni Flutter : manifeste minimal
  (`android:hasCode="false"`), `aapt2 link` (android-35), `zipalign -p 4`,
  `apksigner sign` avec le keystore décodé en temporaire puis supprimé.
  Outils : `deva/binaries/android/build-tools/35.0.0`, `deva/binaries/jdk`.
- gcloud : `CLOUDSDK_PYTHON=C:\Asura\Tools\Python312\python.exe`. En cas de
  « Reauthentication failed » : une seule `gcloud auth login --force`, un seul onglet.

## Fait quand

Tous les packages ddust (Store et `.dev`) affichent **Enregistrée**.
