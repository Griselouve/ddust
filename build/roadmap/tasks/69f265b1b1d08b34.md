# Ajouter une page thèmes et sa promotion sur le site web de ddust

## Pourquoi

Le site web de présentation de `ddust` (hébergé sur Firebase Hosting) doit présenter les différents univers visuels disponibles dans l'application (« Donjon » classique vs le nouveau thème « Gentils Dinosaures ») afin de valoriser la personnalisation de l'expérience familiale et d'attirer différents publics.

## Ce qu'il faut faire

1. Créer une nouvelle page dédiée aux thèmes sur le site web statique de `ddust` (dans `hosting/web/`), déclinée dans les langues supportées.
2. Intégrer des visuels de comparaison (ou captures d'écran côte à côte) illustrant le passage du thème Donjon au thème Gentils Dinosaures.
3. Mettre à jour les pages existantes du site web (notamment la page d'accueil ou de présentation de l'expérience) pour y insérer des accroches et des liens promotionnels pointant vers cette nouvelle page « thèmes ».

## Contraintes et Pièges

- Respecter la structure multilingue du site web sous `hosting/web/` (les 8 langues du projet).
- Utiliser les assets graphiques générés pour le thème Dinosaures (disponibles dans le projet ou via le pipeline assetgen).
- Ne modifier aucun code applicatif Dart ou Python : ce travail concerne exclusivement le site web statique (`hosting/`).
