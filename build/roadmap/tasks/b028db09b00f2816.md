# dvcamera : effacer l'original temporaire d'image_picker après la copie

**Constat vérifié le 2026-09-16.** `image_picker_android` écrit la prise de vue dans le cache de l'app (`ImagePickerDelegate.java:599-603`, `File.createTempFile` dans `getCacheDir()`). `dvcamera.capture()` (`deva/flutter/modules/dvcamera/dvcamera.dart:128-141`) en fait une copie dans `dvphotos/<uuid>.jpg` et **n'efface jamais l'original**. La copie est bien purgée au verdict (`_forgetProof`) et à l'ouverture (`_reconcileProofs`), mais l'original survit, en pleine résolution, jusqu'à ce qu'Android vide le cache ou que l'app soit désinstallée.

**À faire.** Dans `capture()`, après `dest.writeAsBytes(...)`, supprimer `File(shot.path)` (try/catch, sans faire échouer la capture). Valable pour tous les projets qui utilisent `dvcamera`. Mentionner la règle dans le readme du module.
