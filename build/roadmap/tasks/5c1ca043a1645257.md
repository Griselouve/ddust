# Notification de nouvelle inscription en beta

## Pourquoi
Lorsqu'un utilisateur s'inscrit sur la liste d'attente de la beta via le site vitrine (géré par `puhosting`), l'équipe de développement ou le créateur du projet doit en être immédiatement averti pour suivre l'acquisition.

## Ce qu'il faut faire
- Dans la Cloud Function `beta_signup` (hébergée sur le backend Pulumi / `puhosting` ou `ddust`), intercepter chaque nouvelle inscription réussie dans la collection `beta_signups`.
- Envoyer une notification ciblée (par email via `dvmail` / SendGrid / API transitaire ou via FCM sur le canal admin de l'éditeur) résumant la nouvelle inscription (sans compromettre la vie privée, en conservant le hachage ou une simple alerte d'événement).
- S'assurer que le mécanisme respecte les quotas et ne bloque pas l'inscription en cas d'échec de la notification (traitement asynchrone non bloquant).

## Fichiers concernés
- Fonctions Cloud Functions TypeScript associées à `beta_signup` (dans le répertoire Pulumi/backend du projet ou de `deva`).

## Préalables
- Module `dvmail` ou connectivité FCM admin opérationnelle.
- Collection `beta_signups` fonctionnelle.
