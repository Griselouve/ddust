# Avertir le parent créateur de clan s'il tente d'exécuter une tâche seul

## Pourquoi

Lorsqu'un parent vient de créer son clan et se retrouve seul dans le donjon (aucun enfant ou autre membre n'a encore rejoint le clan), l'application lui permet actuellement de sélectionner et d'exécuter des tâches directement. Or, dans la philosophie de *Donjons & Savons*, le rôle des parents est d'administrer le clan, de valider les tâches et de gérer les récompenses, tandis que les aventuriers (ceux qui exécutent les tâches) sont les enfants. 

## Ce qu'il faut faire

1. Détecter lorsqu'un utilisateur administrateur (parent/chef) tente de lancer l'exécution d'une tâche alors que le clan est encore composé uniquement de lui-même (aucun autre membre actif dans le roster).
2. Intercepter cette tentative au moment du clic sur une tâche dans le tiroir (`seltask.*` ou équivalent dans `worker_tasks.dart` / `worker_screen_tiroir.dart`).
3. Afficher un overlay ou une popup explicative non bloquante mais claire (conformément au pattern d'overlay déclaratif de l'application) expliquant que ce rôle est réservé aux enfants/aventuriers et invitant chaleureusement le parent à inviter ses enfants (via le QR code ou le lien d'invitation).
4. Fournir un accès direct (bouton d'action dans la popup) pour basculer vers l'écran d'invitation du clan (`clan_page` ou l'écran de partage d'invitation).

## Fichiers concernés

- `client/modules/worker/worker_tasks.dart` (ou les gestionnaires d'actions du tiroir de combat)
- `client/config/` (déclaration de l'overlay ou de la popup d'avertissement dans les fragments de configuration si nécessaire)
