# Créer l'identifiant et la fiche ddust dans App Store Connect

### Pourquoi

Apple ne permet PAS de créer une app par API : la première fiche se crée à la main, une fois par app. On la fait pour ddust, qui servira d'app pilote pour tout le reste du lot.

⚠ **IRRÉVERSIBLE** : le bundle id et le SKU ne se changent jamais. Attendre que la règle de nommage iOS (tâche « Identité iOS de l'app ») soit tranchée.

### Étapes (sur le PC)

1. Enregistrer l'identifiant : `https://developer.apple.com/account` → **Certificates, Identifiers & Profiles** → **Identifiers** → **+** → **App IDs** → **Continue** → **App** → **Continue**.
   - Description : `ddust`. Bundle ID : **Explicit**, valeur = celle donnée par la règle (ex. `com.grisloup.ddust-client`).
   - Capabilities : cocher **Push Notifications**, **Sign in with Apple**, **Associated Domains** (liens profonds). **In-App Purchase** est coché d'office.
   - **Continue** → **Register**.
2. `https://appstoreconnect.apple.com` → **Apps** → bouton **+** → **Nouvelle app**.
   - Plateformes : **iOS**. Nom : le nom public de l'app (30 caractères max, unique sur tout l'App Store ; modifiable plus tard).
   - Langue principale : **Français**. Bundle ID : choisir celui de l'étape 1.
   - SKU : `ddust` (texte interne, jamais affiché, non modifiable).
   - Accès utilisateur : **Accès complet**. → **Créer**.

### Comment savoir que c'est réussi

- L'app ddust apparaît dans la liste des apps d'App Store Connect, avec l'onglet **TestFlight**.
