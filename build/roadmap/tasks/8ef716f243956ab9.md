# Bout en bout : ddust par TestFlight sur l'iPhone

### Pourquoi

La preuve que le lot est fini : ddust, construit par le builder, envoyé sur TestFlight, installé sur l'iPhone, et tout ce qui marche sur Android y marche.

### Étapes sur l'iPhone (première fois)

1. App Store → chercher **TestFlight** (éditeur Apple) → **Obtenir**.
2. Ouvrir TestFlight, se connecter avec le compte Apple si demandé.
3. Après un `push-testflight`, ddust apparaît dans TestFlight (sinon : ouvrir l'e-mail d'invitation sur l'iPhone → **Afficher dans TestFlight**). Toucher **Installer**, puis **Ouvrir**.
4. Les builds TestFlight expirent au bout de 90 jours : c'est normal.

### Liste de contrôle

- Choix de la région, CGU, création de compte, connexion Google ET Apple.
- Notification reçue app ouverte, en arrière-plan, app fermée ; le son roar.
- Achat d'abonnement avec le compte sandbox, renouvellement, résiliation, restauration.
- Lien d'invitation ouvert depuis Messages : il ouvre l'app au bon écran.
- Caméra / preuve vidéo, QR, suppression de compte.
- Chaque écart trouvé = une tâche dans ce lot (ou celui du module).
