Das Konzept

Den Krieg um die Hausarbeit kennt jeder. So gewinnt man ihn, gemeinsam.

Das Problem (Sie kennen es bereits)

Kinder an der Hausarbeit zu beteiligen heißt wiederholen, verhandeln, manchmal schreien. Die magnetischen Ämtchenpläne landen nach zwei Wochen vergessen am Kühlschrank. Eines fehlte : dass das eigene Zimmer aufzuräumen wirklich spannend ist.

Die Spielmechanik

Aufgaben sind Monster

Jede Hausarbeit wird von einem Monster dargestellt, mit seiner Schwierigkeitsstufe. Das Kind wählt sein Ziel, erledigt die Aufgabe wirklich, meldet « Ich habe das Monster besiegt! », und ein Elternteil prüft, ob die Mission erfüllt ist.

Erfahrung und Stufen

Jeder Sieg bringt den Spieler und den ganzen Clan voran. Die Stufen bringen Titel zum Sammeln : Wer hätte nicht davon geträumt, « Schnüffler schmutziger Socken » zu sein? Und ein Erfahrungsschub erlaubt es den Eltern, einen Nachzügler wieder anzuschieben.

Der Clan ist die Familie

Der Haushalt bildet einen Clan mit seinem Namen, seinem Wappen und seinem Abenteuertagebuch. Zwei Anzeigen steigen im Takt der Siege : die der Clanstufe und die der Truhe. Wenn die Truhe voll ist, wird es Zeit, ihren Inhalt zu teilen.

Die Beute ist ganz real

Die Truhe wird von den Eltern gefüllt : Taschengeld, Familienausflug, Pizzaabend… Beim Öffnen wird das versprochene Geld im Verhältnis zur Erfahrung jedes Einzelnen geteilt, und die Gegenstände werden zugunsten derjenigen verlost, die am wenigsten erhalten haben.

Zwei Rollen, ein Spiel, eine Familie

Die Eltern, Clanchefs

Sie wählen die Aufgaben, prüfen, ob die Mission erfüllt ist, füllen die Beute und steuern das Spiel über einen Verwaltungsbildschirm. Sie können selbst mitspielen oder « außer Konkurrenz » bleiben.

Die Kinder, Helden des Dungeons

Sie erschaffen ihre Figur, wählen ihren Avatar aus einer Heldengalerie, gehen auf die Jagd und sehen ihre Mühe belohnt. Die Kleinsten können ohne Telefon spielen : ein Elternteil legt ihnen ein Profil an und spielt an ihrer Stelle vom eigenen Gerät.

Eine vereinte Familie

Das Spiel ist nur ein Vorwand, das Zuhause ein Spielfeld : Rituale, Pfänder und Ratschläge stärken die Familienbande.

Sie können sich nicht verirren

Das Spiel enthält Tutorials und Tipps, die Sie Schritt für Schritt begleiten.

Auf Vertrauen gebaut

  • Keine Werbung, kein Tracker : kein Analytics, keine Werbekennung.
  • Fotos und Videos werden nie gesendet : das Foto oder das kurze Video ohne Ton (höchstens 15 Sekunden) einer erledigten Aufgabe bleibt auf dem Telefon und wird nie an unsere Server gesendet ; die App hat keinen Zugriff auf das Mikrofon.
  • Jeder Clan ist abgeschottet : Kein anderer Clan kann Ihre Daten sehen. Es gibt weder Verzeichnis noch Suche noch Nachrichtenfunktion : einem Clan tritt man nur auf Einladung eines Erwachsenen bei.
  • Keine Begegnung mit Fremden : kein Chat, keine externen Spieler, keine von Dritten gesendeten Inhalte.
  • Das Geburtsdatum wird nie aufbewahrt : Nur die Unterscheidung Kind/Erwachsener bleibt.
  • Der Laden verkauft nur neue Arten zu spielen : Kulissen, Gegenstände, Charakterklassen. Nie eine Währung zum Aufladen, nie eine Stufe oder ein XP zum Kaufen, nie eine Aufgabe, die ohne Erledigung bestätigt wird, und nur die Erwachsenen des Clans können kaufen.
  • Niemand wird von einem Erwachsenen überstrahlt : Wer als Elternteil mehr Arbeit erledigt als die eigenen Kinder, kann « außer Konkurrenz » spielen : der Clan kommt weiterhin voran, doch Stufe und Fortschritt verschwinden von den Bildschirmen der anderen, und es gibt keinen Anteil an der Beute mehr.

Die Einzelheiten stehen in unserem Rechts- und Datenschutzbereich.

Donjons & Savons wird von einem Elternteil und unabhängigen Entwickler entworfen und entwickelt (grisloup.com), zuerst für die eigene Familie, dann für Ihre.
